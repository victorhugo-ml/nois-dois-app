# Dados de demonstração

Nenhum dado real da aplicação é distribuído neste repositório.

Para screenshots ou demonstrações públicas, use dados inteiramente fictícios, por exemplo:

- Pessoa 1 / Pessoa 2;
- eventos genéricos;
- valores financeiros fictícios;
- mensagens como "Mensagem de demonstração";
- imagens geradas especificamente para demonstração ou assets sem pessoas reais.

Não exporte o banco de produção para criar uma demo pública.
