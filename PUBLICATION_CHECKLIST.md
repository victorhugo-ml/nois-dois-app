# Checklist antes de tornar o repositório público

- [ ] Confirmar que nenhum e-mail pessoal aparece no código.
- [ ] Confirmar que não há senha, token privado ou service-account key.
- [ ] Substituir configurações `YOUR_*` apenas na cópia usada para deploy privado.
- [ ] Revisar `database.rules.json`.
- [ ] Revisar `storage.rules`.
- [ ] Confirmar que o histórico Git antigo não contém dados que você não deseja publicar.
- [ ] Adicionar screenshots sem informações pessoais.
- [ ] Testar o README em um clone limpo.
- [ ] Manter a descrição do projeto transparente sobre o uso de ferramentas de IA.
